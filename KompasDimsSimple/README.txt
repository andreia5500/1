Технолог 2.0 · версия 2.1.0

Главное окно
Слева — модули по порядку работы технолога: 1 Размеры с чертежа,
2 Карта контроля, 3 Допуски на эскизе, 4 Ведомость оснастки,
5 Нумерация листов, 6 Проверка УП. Все окна устроены одинаково:
шапка, шаги 1-2-3, внизу «Журнал отладки», «Закрыть» и одна синяя
кнопка главного действия.

Запуск
Распакуйте архив в отдельную папку. Запустите START.bat.
Нужны Windows, установленный КОМПАС, Python 3 и pywin32.
Разрядность Python должна совпадать с КОМПАСом. Установщика и .exe нет.

Работа
1. Откройте чертёж.
2. Отметьте размеры. Двойной щелчок — изменить размер, вид или меритель.
3. Выберите действие: карта контроля, допуски на эскизе или ведомость.
Надписи и ТТ не считываются. Заданные допуски сохраняются при пересчёте.
Минус передаётся нижним индексом, плюс — верхним.
В карте размеры группируются по виду и инструменту, между инструментами
оставляется пустая строка. При нехватке места предусмотрено продолжение.
Неопределённый диаметр требует ручного выбора вала/отверстия.

Ведомость оснастки
Выберите ТП. Справа показаны только листы МК ВО.
Выделите нужные листы, для нескольких — Ctrl + щелчок.
Нажмите «Собрать со всех листов» или выберите источники слева
и нажмите «Собрать выбранные».
Проверьте список и предварительный просмотр, затем «Записать в МК ВО».
Точные повторы объединяются; разные модели сохраняются.
Источники: МК — строки Т графы 2000; ОК ТК — меритель в графе 2001;
КЭ ЧПУ — инструмент в графах 2002/2006. При отсутствии общей графы
применяются поддерживаемые отдельные ячейки прежнего оформления.
Назначение: строки ведомости выбранных листов МК ВО. Для оформлений 200 и 24
каждая строка — отдельная графа 3456…3472 (17 строк на лист), заголовок группы
пишется жирным. Для прочих оформлений — графа 2000; если её нет в оформлении,
запись отклоняется: текст не был бы виден.

Нумерация листов
«Нумерация листов…» проставляет номер листа внутри каждого документа ТП
(ячейка сверху справа на листах-продолжениях). Сначала показывается
таблица «лист → документ → номер», запись — по кнопке.

Проверка УП (шаг 6)
Три вкладки: «Автомат · Diamond», «HAAS VF-2/3», «IMV 10.55».

HAAS и IMV (фрезерные)
1. Перетащите в окно файлы .nc (можно сразу все файлы детали и папки)
   или нажмите «Добавить файлы…» / «Папка…». Файлы можно добавлять
   несколько раз — расчёт обновляется сразу.
2. Каждая программа с M30/M02 — отдельный установ (карточка с временем,
   полоской долей времени и итогом проверки). Подпрограммы находятся сами:
   HAAS — M98 P… (отдельный файл O…), M97 P… (метка N в той же
   программе); IMV (HNC-8) — M98 P… (блок O… в том же файле или
   отдельный файл). Поддерживаются L-повторы, M99 P, G65, макросы
   (#, IF/GOTO/THEN, WHILE/DO/END, SIN/COS/FIX…).
3. Вверху — общее время всех установов. Двойной щелчок по карточке —
   подробности: текст программы, «Сводка» (доли времени, кадры «/»,
   остановы M00), «Инструменты» (T, H/D, S, F, отверстия, время),
   «Проверка кода» (двойной щелчок — к строке), «По кадрам».
Имитация: ускоренный ход по каждой оси (по умолчанию 50 %) с разгоном,
подача G94/G95/G93 с замедлением на углах, дуги и винтовые, 4-я ось A,
циклы G73/G74/G76/G81–G89 (Q-проходы, отвод, повторы, паузы), G84 —
подача = S × шаг и реверс, G12/G13 и G70–G72 HAAS, смена инструмента
с подъёмом Z, разгон шпинделя, G04 (HAAS: P с точкой — секунды, без —
мс; HNC-8: P — мс, X — секунды), G28/G53, G52, G68, G51.
Проверки: коды, которых нет у станка (G154/M97 на IMV, G54.1/G108/M45
на HAAS), M6 без T, нет G43 после смены, G43 H ≠ T, G41/G42 без D или
на дуге, подача при остановленном шпинделе или без F, обороты/подача
больше паспорта, резание без СОЖ, шаг G84 не стандартный и M3/M4 не по
циклу, неверный радиус/центр дуги, повтор K в G90 (одно отверстие
несколько раз), M98 на несуществующую программу (с подсказкой M97),
повтор номера O, выход за ход по G53 и по размаху, кадры после M30,
бесконечные циклы, незакрытые G68/G51/G52, HNC-8: M98/M99 отдельным
кадром, G80 перед M99, G04 P с точкой.
«Параметры станка…» — свои для каждого станка (модель VF-2/VF-3, ускоренные,
разгон, смена инструмента, разгон шпинделя, отвод G73/G83, режим циклов
HNC-8 FANUC/HNC-8, кадры «/», M01, ход и ноль детали); сохраняются в
%LOCALAPPDATA%\KompasDimsSimple\mill_params_haas.json / _imv.json.
Значения по умолчанию — типовые, уточните по паспорту своего станка.

Автомат · Diamond
Слева — программы систем S1/S2 и
подпрограммы: «Открыть УП…» загружает файл (любое расширение, UTF-8 или
cp1251). Подпрограммы O5000–O5002 встроены; прочие M98 ищутся в папке
УП и запоминаются в постоянной библиотеке подпрограмм. Справа — результат:
  «Время цикла» — общее время, по системам (конец, своя работа, резание,
   ожидание), барьеры !L и замечания расчёта;
  «Проверка кода» — ошибки и предупреждения как на станке (P36, P37, P231,
   P293/P294, P230, рассинхронизация !L, циклы P/Q и др.); двойной щелчок
   — переход к кадру;
  «По кадрам» — время каждого кадра с нарастающим итогом.
«Параметры станка…» — ускоренный ход, M/T-коды, разгон шпинделя,
G83, обороты; сохраняются в %LOCALAPPDATA%\KompasDimsSimple\nc_params.json.
Движок nc_engine.py — перенос модуля «Проверка» DiamondCAM/Post,
сверен с ним по каждому кадру на O6017/O6018 и O6108/O6109.

Проверка записи
Проверяются номер штампа, состав листов, исходные графы и образец.
После записи текст, стиль и шрифт читаются через API5.
При необходимости обновляется штамп, окно полностью перерисовывается.
Затем текст и форматирование читаются через API7.
Все листы ещё раз проверяются в обратном порядке; сравниваются
прочие заполненные графы выбранных листов и инструмент в источниках.
При ошибке затронутые графы восстанавливаются в обратном порядке.
Сообщение указывает, подтверждено ли восстановление обоими API.
Проверка данных API не подтверждает их видимость на экране.
Окончательно оцените листы в самом КОМПАСе.
ТП автоматически не сохраняется. После проверки — Ctrl+S в КОМПАСе.

Журнал отладки
Доступен из главного окна и всех рабочих окон.
Журнал дописывается, предыдущие ошибки не стираются.
Сохраняются время, версия и номер операции, путь документа, листы,
графы, текст, стили, шрифты, результаты чтения, команды COM и
полная ошибка с HRESULT, traceback и цепочкой исключений.
Ошибки чтения отдельных размеров также показываются в предупреждениях.
«Проверить листы ТП» в ведомости перечисляет графы выбранных листов
через оба API и сохраняет подробный диагностический отчёт.
«Сохранить журнал» создаёт ZIP с историей и резервными отчётами.
Файлы: %LOCALAPPDATA%\KompasDimsSimple.
Резервные JSON — тексты и параметры граф, не полная копия CDW.

Интерфейс
Единая светлая тема, упорядоченные действия, прокрутка таблиц,
изменяемые области списка и предварительного просмотра.
При работе с КОМПАСом действия блокируются; журнал остаётся доступным.
После ошибки окно показывает остановку и необходимость перечитать данные.

Проверки описаны в CHECKS.txt.
Реальный Windows/КОМПАС здесь недоступен: фактическая запись в вашем
открытом ТП, вид листов и визуальный запуск новой оболочки не подтверждены.
