# Мои финансы

Android-приложение для личного учёта: разбирает PDF-выписки банков и показывает,
куда уходят деньги, прогноз остатка на конец месяца, лимиты, цели и план погашения кредиток.
Все данные хранятся только на телефоне.

## Установка на телефон

Последняя версия: https://github.com/andreia5500/1/releases/latest/download/MoiFinansy.apk

Откройте ссылку на телефоне, скачайте и установите (Android попросит разрешить установку из браузера).
Новые версии ставятся поверх, данные сохраняются.

## Какие выписки понимает

- СберБанк Онлайн — «Выписка по счёту дебетовой карты» и «… кредитной карты» (PDF)
- Т-Банк — «Выписка по договору» (дебетовые и кредитные, PDF)

Каждая выписка сверяется с итогами в её шапке («Пополнение / Списание», «Поступления / Расходы»).

## Разработка

```
npm ci
npm run dev        # открыть в браузере
npm test           # тесты; с реальными выписками: FIN_PDF_DIR=/путь/к/pdf npm test
npm run build && npx cap sync android
```

APK собирается в GitHub Actions (`.github/workflows/finance-apk.yml`) при каждом изменении в папке `FinanceApp`.
Выписки (*.pdf) в репозиторий не добавляются — они в `.gitignore`.

Устройство: TypeScript + Preact (интерфейс), pdf.js (чтение PDF), Capacitor (Android-обёртка).
Логика — в `src/core`: `parsers/` (разбор выписок), `classify.ts` (категории и переводы между своими счетами),
`analytics.ts`, `forecast.ts`, `debts.ts`.
