# Дача PRO — дашборд Home Assistant

`/dacha-pro` в Home Assistant. Вид «Обзор» — одна карточка `custom:dacha-pro-card`
(panel view), которая рисует всю страницу по макету: боковое меню, шапка со статусом
и чипами (погода, ИБП, Frigate), охрана, мощность сети, улица/дом, датчики безопасности,
климат с графиком за 24 ч, бассейн, свет, нагрузки и автоматы, полив, камеры, система.

- `dacha-pro-card.js` — карточка; в HA зарегистрирована как inline-ресурс (module).
  Сущности заданы константами в начале файла.
- `dashboard.json` — конфиг вида «Обзор».

Опции карточки: `title` (по умолчанию «Дача»), `cameras_path` (куда ведёт пункт меню
«Камеры»), `host_label` (подпись в блоке «Система», по умолчанию версия HAOS).

Тап по чипу переключает устройство, тап по плитке со значением открывает more-info.
Кнопка с солнцем переключает тёмную/светлую тему (запоминается в браузере).

## v2

- Узкая панель-рельс с иконками вместо широкого меню, компактные шрифты и карточки.
- Страница сама подгоняется под высоту экрана (без прокрутки) на планшете и мониторе;
  на телефоне (уже 760 px) — обычная прокрутка в одну колонку. Опции: `fit: false`, `max_scale`.
- «Лето / Зима» в шапке: летом блоки «Бассейн» и «Полив», зимой на их месте
  «Отопление» (уставки −/+ и режимы Дежурный/Дома/Комфорт) и «Обогреватели».
- Иконки MDI в одном цвете: синие у включённого, серые у выключенного.
