# Умный дом — Android-клиент для Home Assistant

Лёгкое приложение (~90 КБ, без сторонних библиотек) для управления домом через
Home Assistant.

- Вход по логину и паролю Home Assistant (поддерживается двухфакторный код).
  Пароль в телефоне не хранится — только токен; «Выйти» отзывает его на сервере.
- Состояния обновляются мгновенно (WebSocket API).
- Быстрый старт: последние состояния показываются сразу из кэша, свежие
  подгружаются в фоне.

## Вкладки

| Вкладка | Что там |
|---|---|
| Главное | закреплённые элементы (удерживайте любой элемент → «Закрепить»); пока ничего не закреплено — охрана, люди, климат, шторы, свет, сцены |
| Управление | всё, чем можно управлять: розетки, выключатели, отопление, шторы, сцены, скрипты, кнопки |
| Датчики | датчики по группам: безопасность, двери, движение, температура, электричество… |
| Камеры | снимки камер, обновляются каждые 10 с; нажатие — на весь экран (раз в 2 с) |
| Все | все сущности с поиском |

Служебные сущности (настройки и диагностика устройств, скрытые) видны только во
вкладке «Все».

## Управление

- Переключатели — нажатие на строку или тумблер.
- Свет — нажатие на строку открывает яркость.
- Отопление — кнопки − / + (отправка через 0,7 с после последнего нажатия);
  нажатие на строку — режимы, пресеты, точная температура.
- Шторы — ▲ ■ ▼; нажатие на строку — положение в процентах.
- Охрана — нажатие открывает постановку/снятие (с кодом, если он нужен).
- Сцены, скрипты, кнопки — ▶.
