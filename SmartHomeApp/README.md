# Умный дом — Android-клиент для Home Assistant

Лёгкое приложение (~90 КБ, без сторонних библиотек) для управления домом через
Home Assistant.

- Вход по логину и паролю Home Assistant (поддерживается двухфакторный код).
  Пароль в телефоне не хранится — только токен; «Выйти» отзывает его на сервере.
- Состояния обновляются мгновенно (WebSocket API).
- Быстрый старт: последние состояния показываются сразу из кэша, свежие
  подгружаются в фоне.

## Дизайн

«Светлый минимализм» из макета: тёплый серый фон, белые карточки, один синий акцент,
красный — только для тревог. Три раздела в нижнем меню.

| Раздел | Что там |
|---|---|
| Главная | тревоги (протечка, дым, сработавшая охрана, пропало электричество) красной карточкой сверху — «Скрыть» убирает её, пока датчик не сработает снова; охрана («Я дома» / «Ухожу» / «Снять с охраны»); на улице и в доме; мощность сети с графиком за 6 часов; ИБП (заряд, сколько продержится, нагрузка); двери, протечка, дым и CO; отопление по комнатам с −/+; события за 12 часов; избранное; команды через ВК |
| Камеры | сетка снимков 2×N (видимые обновляются раз в 5 с), фильтры «Все / Движение / Люди» по датчикам Frigate, последнее появление человека; нажатие — живое видео на весь экран (MJPEG через Home Assistant) |
| Ещё | все устройства: «Управление», «Датчики», «Все» с поиском; выход из аккаунта |

Долгое нажатие на карточку температуры или мощности — выбрать, какой датчик там показывать.

## Управление

- Переключатели — нажатие на строку или тумблер.
- Свет — нажатие на строку открывает яркость.
- Отопление — кнопки − / + (отправка через 0,7 с после последнего нажатия);
  нажатие на строку — режимы, пресеты, точная температура.
- Шторы — ▲ ■ ▼; нажатие на строку — положение в процентах.
- Охрана — нажатие открывает постановку/снятие (с кодом, если он нужен).
- Сцены, скрипты, кнопки — ▶.

## Сборка

```bash
./build.sh   # -> build/SmartHome.apk
```

## Команды через ВК

Когда интернет до дома заблокирован, а ВК работает: кнопка команды открывает чат
группы во ВКонтакте и вписывает туда `/end`, `/home` и т. д. — остаётся нажать
«Отправить». Для автоматической вставки один раз включите «Умный дом: команды в ВК»
в Настройках → Специальные возможности; без этого команда копируется для вставки.

## Безопасность

Снятие с охраны требует отпечаток пальца или PIN-код телефона (если на телефоне
стоит блокировка экрана).
