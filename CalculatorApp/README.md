# Калькулятор для Android

Простой калькулятор: `+ − × ÷`, проценты, скобки, десятичная запятая,
предпросмотр результата во время ввода, точная арифметика (`0,1 + 0,2 = 0,3`).

- Готовый файл: `Calculator.apk` — скачать на телефон и установить
  (разрешить установку из неизвестных источников).
- Android 5.0 и новее.

## Сборка

```bash
sudo apt-get install android-sdk-platform-23 aapt dalvik-exchange zipalign apksigner
./build.sh        # -> build/Calculator.apk
```

GitHub Actions (`.github/workflows/calculator-apk.yml`) собирает APK при каждом
изменении в папке `CalculatorApp/` и прикладывает его к запуску как артефакт.

`debug.keystore` — отладочный ключ подписи (пароль `android`), он хранится в
репозитории, чтобы новые версии ставились поверх старых. Для Google Play нужен
отдельный секретный ключ.

## Кнопки

| Кнопка | Действие |
|---|---|
| `AC` / `C` | очистить |
| `⌫` | стереть символ, долгое нажатие — очистить всё |
| `( )` | открыть или закрыть скобку |
| `%` | процент: `200 × 10%` = 20 |
